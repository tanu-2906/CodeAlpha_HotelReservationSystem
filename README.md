Hotel Reservation System

Features

- Search and view available rooms
- Room categories: Standard, Deluxe, and Suite
- Book hotel rooms
- Cancel reservations
- Simulate payments
- View booking details
- Store booking information using file handling

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling

Project Files

- Java source files: Application logic and reservation management
- "booking.txt": Stores booking information

How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the main Java file.
4. Follow the instructions displayed by the application.
